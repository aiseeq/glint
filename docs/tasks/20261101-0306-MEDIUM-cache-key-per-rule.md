## Приёмка
- После установки сборки с правкой одного правила первый прогон на корне sc2go: пересчитаны только находки этого правила; время — было/стало.
- Сборка с правкой core сбрасывает весь кэш (тест).
- `graft consumers` — 0 различий.

## Варианты
1. Ключ находок правила — отпечаток исходников, от которых оно зависит (пакет правила + его внутренние зависимости в модуле glint, go list -deps), вычисленный при сборке и вшитый в бинарь; ядро (core, обход, кэш) — общий отпечаток, меняется — сброс всего.
   - Цена: средняя (генерация отпечатков в graft build/install, ключ записи кэша по правилу).
   - Выигрыш: выпуск, не трогавший правило, не сбрасывает его находки; первый прогон после выпуска — пересчёт только изменённых правил.
2. Ничего не менять; цену платят первые прогоны после выпуска (17–55 с на больших корнях).
