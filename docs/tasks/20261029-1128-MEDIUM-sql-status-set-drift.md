## Что сделать
- R3 из запроса 29.10 (см. sql-predicate-copies-constant): расширение `value-set-drift` списками значений в тексте SQL: `col IN ('a','b')` и `col = ANY('{a,b}')` с привязкой колонки к таблице (алиас → таблица). Списки от 2 значений одной колонки той же таблицы: набор, повторённый в 3+ литералах без константы, — «объявите константу»; набор, отличающийся на одно значение от набора, что встречается 2+ раз, — расхождение. Сторож перехода — список в WHERE UPDATE/DELETE, где тот же WHERE закрепляет одну строку (`id = $N`), — не набор.
- Зависит от общего модуля (тикет sql-predicate-copies-constant).
