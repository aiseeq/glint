## Что сделать
Запрос мастера потребителя А (29.10): во фронте `['rejected','failed','cancelled']` и `new Set(['completed', ...UNSUCCESSFUL])` — группы статусов вывода, которые бэкенд держит сам (case-клауза из констант, список-переменная констант). Аналог R3 (sql-status-set-drift) для TS. `value-set-drift` сравнивает наборы из констант только с наборами из констант (≥4), а «часть набора» считает своим набором — пропуск.
Нужно: TS-список из строковых литералов (массив, аргумент `new Set(...)`, с раскрытием `...X` списка того же файла), значения которого (≥2) ровно равны значениям Go-группы констант одного объявленного набора (список констант, case-клауза, ключи map-членства) → находка «группа уже объявлена в бэкенде в <файл:строка>». Пример с generated-типами из запроса у потребителя не подходит: тип статусов вывода у него не сгенерирован, группа — только в Go.
