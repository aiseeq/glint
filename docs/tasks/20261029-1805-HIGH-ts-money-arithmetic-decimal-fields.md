## Что сделать
Ложный пропуск `frontend-money-arithmetic` (запрос мастера потребителя А, 29.10). Правило построчное: ловит только `parseFloat|Number` с денежным словом в аргументе и оператор на той же строке. Не видит:

1. парсеры-хелперы проекта (`toNumberOr(x, null)`, `toNumber(x)`);
2. поля, чей тип — decimal-строка API (Go-поле `*Decimal` с json-именем, TS-поле с типом `\w*Decimal`), когда имя не из словаря денег (`totalValueUsd`, `netUsd`);
3. арифметику над переменной, которой присвоен разбор (`const v = cond ? toNumberOr(r.totals.totalValueUsd, null) : null` … `v - w`);
4. `Math.round/floor/ceil/trunc` над разобранной суммой.
Бриф бойцу: scratchpad brief-ts-money-arith.md.
