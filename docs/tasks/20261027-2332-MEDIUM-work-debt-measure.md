## Постановка
Задание лида через админа рабочего пространства по слову пользователя (27.10, пункт D: «порог glint становится одинаковым (сначала замер долга в `~/work`)»). Сейчас гейт рабочих проектов пропускает medium и low. Только замер: порог, конфиги и код проектов не трогать; замороженные проекты не считать.

## Что сделать
- Для каждого проекта `~/work` с glint в гейте — установленный glint с конфигом проекта, все severity, по одному проекту через `graft exec --heavy`.
- Таблица проект × severity и разбивка по правилам (топ).
- Итог — лиду и копией админу рабочего пространства; решение о пороге — за лидом с пользователем.

## Чем проверить
- Число находок high и выше в таблице совпадает с тем, что пропускает гейт сейчас (ожидается 0 или известные исключения проекта).
- Сырые JSON по проектам — `~/.local/share/glint-history/debt-20261027/` (вне репо), версия glint — там же.
