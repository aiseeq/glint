# glint check appends a run line: project, version, findings and time per rule

Статус: открыт

## Вход
- Сон, обход design 31.10: отдачу правил никто не считает — след срабатывания за неделю у 80 из 634 правил; из 30 правил с 27.10 в нескольких проектах сработали 3, ни разу после рождения 21. Предложение: `glint check` дописывает строку в журнал (время, проект, версия, находки по правилам, время правил; JSON с --timing их уже считает).
- prior «журнал срабатываний правил glint отдача» 31.10 03:0x — прежних решений нет.

## Что сделать
1. Где писать (XDG state, ротация), формат строки jsonl, без влияния на код выхода; отказ записи — предупреждение в stderr, не сбой.
2. Отчёт: `glint stats` или скрипт — правила без находок за N дней, CPU правил.

## Приёмка
- Прогон glint check на потребителе дописывает одну строку с находками по правилам; два параллельных прогона не портят файл.
